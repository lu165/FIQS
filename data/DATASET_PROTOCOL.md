# Dataset Organization and Evaluation Protocol

This project uses task-specific datasets rather than merging heterogeneous forestry datasets into a single corpus followed by random splitting.

## Forestry Knowledge Evaluation

Dataset:
510林业专业测试集

Size:
510 evaluation samples

Usage:
Independent forestry-domain knowledge evaluation.

## Biomass Equation Benchmark

Dataset:
Biomass equation benchmark

Size:
522 test cases

Usage:
Equation recommendation and applicability verification.

The benchmark dataset is maintained separately and can be obtained from the corresponding author when required.
